# ws4-02-mvp-curriculum: Учебная Программа MVP (Базовый Курс)

> **ABSTRACT:** Спецификация определяет дидактический план (Curriculum) из трех базовых уроков для этапа MVP. Документ регламентирует образовательные цели, ожидаемые структуры кода Ученика и критерии успешности (Acceptance Criteria) для каждой задачи.

## 1. Didactic Spiral (Спиральное обучение)

При генерации скриптов задач, ИИ-агент `SHALL` строго соблюдать принцип нарастающей сложности. Каждая новая задача `SHALL` требовать от ученика использования инструмента из предыдущего урока ПЛЮС введения строго одной новой синтаксической концепции языка Python.
Задачи `SHALL` следовать контракту зон из `[[ws4-01-task-template-contract]]`.

## 2. Lesson 1: Linear Algorithms (Линейные алгоритмы)

* **Целевой файл:** `task_01_lines.py`
* **Педагогическая цель:** Ознакомление с синтаксисом вызова методов, концепцией относительной геометрии ("вперед", "направо") и базовой отрисовкой.
* **Требования к Задаче:**
  * Ученик `SHALL` написать код для постройки квадратного периметра (рамки) размером 6x6 блоков.
  * Учебный комментарий `SHALL` прямо подсказывать использование команд `bot.forward()` и `bot.right()`.
* **Ограничения (Constraints):**
  * В этом уроке `SHALL NOT` требоваться использование циклов. Код ученика может состоять из 8 последовательных строк (линейное исполнение).
* **Критерий успеха (Validation Zone):**
  * Скрипт `SHALL` успешно отработать без выброса исключений `BoundaryError` (удержание в рамках Участка).

## 3. Lesson 2: Iteration & Z-Axis (Циклы и Вертикаль)

* **Целевой файл:** `task_02_loops.py`
* **Педагогическая цель:** Осознание концепции `DRY` (Don't Repeat Yourself), введение циклов `for` и базовой 3D-кинематики (`up()`).
* **Требования к Задаче:**
  * Ученик `SHALL` построить сплошную вертикальную стену (например, высотой 4 блока и длиной 8 блоков).
  * Setup-зона преподавателя `SHALL` инициализировать бота и включить отрисовку блоками (например, `bot.color("brick")`).
  * Комментарии в Зоне Ученика `SHALL` наводить на использование вложенных циклов (`[Reference Implementation: внешний цикл по высоте, внутренний по длине]`).
* **Критерий успеха (Validation Zone):**
  * Постройка возведена без выхода за границы, бот успешно использует метод возврата в начало строки после каждого уровня.

## 4. Lesson 3: Sensors & Conditionals (Сенсоры и Интерактивность)

* **Целевой файл:** `task_03_labyrinth.py`
* **Педагогическая цель:** Введение управляющих конструкций `if/else`, бесконечных циклов `while` и взаимодействия с окружением через сенсоры (обратная связь от `[[Server Node]]`).
* **Требования к Задаче:**
  * Ученик `SHALL` написать алгоритм прохождения заранее подготовленного лабиринта (Генерация лабиринта выполняется в Зоне Преподавателя).
  * Алгоритм ученика `SHALL` использовать метод `bot.detect()` для проверки наличия стены спереди и метод `bot.is_goal_reached()` для условия выхода из цикла.
  * Setup-зона преподавателя `SHALL` содержать вызов `bot.wait_for_guest_trigger()`, демонстрируя ученику концепцию ожидания сигнала от Гостя (Зрителя).
* **Ограничения (Constraints):**
  * Цикл `while` ученика `SHALL` содержать программный предохранитель (например, счетчик `steps < 100`), чтобы защитить процесс от бесконечного зависания при логической ошибке.
* **Критерий успеха (Validation Zone):**
  * Зона проверки `SHALL` анализировать возвращаемое значение `bot.is_goal_reached()` и выводить в `stdout` поздравление с успешным прохождением испытания.
