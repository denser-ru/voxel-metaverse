# ws4-03-admin-tooling: Инструментарий Преподавателя (Admin Tooling)

> **ABSTRACT:** Спецификация описывает контракты использования административных расширений `[[Python SDK]]` для подготовки учебных полигонов. Документ регламентирует мгновенную массовую застройку (Bulk Placement) и расстановку триггеров финиша, необходимых для реализации интерактивных испытаний (Challenges).

## 1. ChallengeBuilder Concept (Концепция Строителя Испытаний)

Для подготовки Участка к выполнению задачи учеником, ИИ-агент `SHALL` использовать специализированный класс-расширение, доступный в SDK (`[Reference Implementation: класс ChallengeBuilder или AdminBuilder, наследующий Turtle]`).

* Инструментарий `SHALL` применяться ИСКЛЮЧИТЕЛЬНО в "Зоне Преподавателя" (Setup Zone) файлов уроков.
* Использование административных методов в "Зоне Ученика" (Student Zone) `SHALL NOT` допускаться, чтобы не нарушать дидактический процесс.

## 2. Instant World Generation (Мгновенная застройка)

Преподавательский скрипт `SHALL` подготавливать полигоны мгновенно, минуя механизмы визуальной задержки (Atomic Stepping).

* Для возведения стен, лабиринтов и препятствий ИИ-агент `SHALL` использовать методы массовой установки (`[Reference Implementation: метод build_from_json(nodes) или build_walls_matrix(matrix)]`).
* Эти методы `SHALL` формировать единый массив блоков (относительно User Space) и делегировать его отправку сетевой команде `bulk_set_nodes` (описанной в контрактах протокола).
* Инструментарий `SHALL` гарантировать, что сгенерированная матрица препятствий не выходит за разрешенные границы Участка $X, Z \in [-15..15]$.

## 3. Goal Node Placement (Установка точки финиша)

Для функционирования механики проверки победы (как описано в `[[ws4-02-mvp-curriculum]]` для Урока 3), инструментарий `SHALL` предоставлять метод точечной установки триггера.

* Агент `SHALL` использовать выделенный метод (`[Reference Implementation: place_goal(x, y, z)]`) для установки целевого блока.
* Этот метод `SHALL` устанавливать блок с алиасом `"goal"`, который `[[Server Node]]` распознает как триггер для генерации сетевого события `"GOAL_REACHED"`.
* Координаты точки финиша `SHALL` располагаться в зоне досягаемости алгоритма ученика и не перекрываться непроходимыми препятствиями.

## 4. Setup Zone Integration (Интеграция в Урок)

КОГДА ИИ-агент генерирует файл урока, требующий наличия лабиринта (например, `task_03_labyrinth.py`), он `SHALL` соблюдать следующий жизненный цикл в "Зоне Преподавателя":

1. **Очистка:** Вызов `wipe()` для гарантированного удаления предыдущих построек на Участке.
2. **Генерация карты:** Вызов методов `ChallengeBuilder` для мгновенного возведения стен лабиринта на основе заранее подготовленного массива (JSON/List).
3. **Установка цели:** Размещение `goal` блока в конце лабиринта.
4. **Телепортация Черепашки:** Принудительное перемещение стартовой позиции бота в начало лабиринта без рисования (с поднятым пером).
5. **Блокировка (Опционально):** Вызов `wait_for_guest_trigger()`, чтобы зафиксировать состояние полигона до прихода Зрителя (Гостя).
