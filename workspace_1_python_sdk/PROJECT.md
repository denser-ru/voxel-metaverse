# PROJECT: Client Python SDK (The Student Node)

> **ABSTRACT:** Данный файл описывает бизнес-смысл, целевую аудиторию и высокоуровневую архитектуру клиентского Python SDK (`voxel_turtle`). ИИ-агенты `SHALL` использовать этот документ для понимания того, для кого они пишут код, и какие пользовательские ограничения (UX Constraints) существуют в этом домене.

## 1. System Passport (Бизнес-миссия: "Что и Зачем")

**Продукт:** Автономная Python-библиотека для управления 3D-черепашкой в удаленном воксельном мире.
**Целевая аудитория (Конечный пользователь):** Школьники 11–14 лет. Они используют базовые среды разработки (`IDLE`, `Thonny`, `VS Code`) на домашних компьютерах, часто без прав администратора. 

**Глобальная цель (The Why):** 
Сделать переход от классического программирования 2D-черепашки (модуль `turtle`) к программированию 3D-мира абсолютно бесшовным. Ученик `SHALL NOT` задумываться о том, что под капотом работают TCP-сокеты, сетевые задержки или сериализация JSON. SDK `SHALL` скрыть всю техническую грязь, предоставив чистый, понятный объектно-ориентированный интерфейс.

## 2. Architectural Boundaries (Границы Архитектуры)

Рабочее пространство `python-sdk` является `[[Client Node]]` в нашей глобальной экосистеме.

* **Изоляция от сервера:** SDK ничего не знает о внутреннем устройстве сервера (какой там движок, как физически ставятся блоки). SDK общается с абстрактным `[[Server Node]]` исключительно по правилам из `shared_contracts/`.
* **Zero-Dependency (Нулевые зависимости):** Чтобы школьник мог просто скачать один файл `voxel_turtle.py` и сразу запустить его, SDK `SHALL` использовать только стандартную библиотеку Python 3.10+ (без `pip install`).
* **Топологический комфорт:** Ученики работают в привычной декартовой системе (где центр участка — это `0,0,0`). SDK берет на себя обязанность скрыто переводить эти координаты в сетевой формат (Network Space) и обратно.
* **Fail-Fast (Цена ошибки):** ЕСЛИ робот врезается в стену или выходит за границы участка, SDK `SHALL` немедленно выбросить локализованное (понятное на языке ученика) исключение, останавливая скрипт. Скрывать ошибки (silent failures) категорически запрещено.

## 3. Client Domain Glossary (Глоссарий Клиента)

* **Turtle:** Главный класс, импортируемый учеником. Хранит локальное состояние (координаты, поворот) и управляет TCP-соединением.
* **Atomic Stepping (Декомпозиция шагов):** Внутренний механизм SDK. Если ученик вызывает `bot.forward(5)`, SDK разбивает это на 5 отдельных сетевых запросов с микро-паузами (`delay`) между ними. Это нужно, чтобы зрители видели плавную анимацию, а не телепортацию.
* **AdminBuilder:** Вспомогательный класс, наследующий Turtle. Предназначен не для детей, а для преподавателей и ИИ. Позволяет мгновенно загружать целые уровни (лабиринты) через сетевую команду массовой застройки, минуя `Atomic Stepping`.
* **User Space:** Система координат, комфортная для ученика. Центр участка находится в `(0, 0, 0)`. Диапазоны осей $X$ и $Z$: `[-15..15]`.
