# PROJECT: Luanti Simulation Node (The Server Mod)

> **ABSTRACT:** Данный файл описывает бизнес-смысл, архитектурные границы и философию серверного модуля `voxel_bot` для воксельного движка Luanti. ИИ-агенты `SHALL` использовать этот документ для понимания того, как их Lua-код встраивается в жесткие рамки однопоточной высоконагруженной симуляции.

## 1. System Passport (Бизнес-миссия: "Что и Зачем")

**Продукт:** Серверный плагин (Mod) для движка Luanti 5.8+, выступающий в роли 3D-терминала и физического валидатора.
**Главная цель (The Why):**
Обеспечить абсолютно безопасную, изолированную и визуально привлекательную среду для рендеринга алгоритмов, написанных учениками. Сервер выступает в роли "судьи": он проверяет столкновения, не дает школьникам выйти за границы своего участка и аппаратно блокирует попытки гриферства (разрушения чужих построек). 
Особая миссия модуля — обеспечить **Офлайн-Витрину**: способность сервера автономно "проигрывать" записанные шаги алгоритма для зрителей из браузера, даже когда ученик закрыл свой ноутбук.

## 2. Architectural Boundaries (Границы Архитектуры)

Рабочее пространство `luanti-mod` является `[[Server Node]]` в нашей глобальной экосистеме.

* **Изоляция от Клиента:** Сервер ничего не знает о языке, на котором пишет ученик (будь то Python, JS или Scratch). Он оперирует исключительно входящими потоками NDJSON через TCP-сокет по контрактам `shared_contracts/`. Любой входящий пакет `SHALL` считаться недоверенным (Untrusted).
* **Zero-Lag Philosophy (Философия нулевого лага):** Движок Luanti работает в одном главном потоке (Main Thread). Если Lua-мод зависнет на 1 секунду, все игроки на сервере получат "фриз". Модуль `SHALL` реализовывать все I/O операции асинхронно, а тяжелые задачи (массовая установка блоков) дробить на микро-порции (Time Slicing).
* **Бессерверный Откат (Stateless Replay):** Для защиты жесткого диска сервера (Disk I/O) от износа при частых стартах демо-режима, система `SHALL` хранить дельты изменений блоков исключительно в оперативной памяти (In-Memory Rollback).

## 3. Server Domain Glossary (Глоссарий Сервера)

* **globalstep:** Базовый тактовый импульс движка Luanti (Tick). Вызывается десятки раз в секунду. Вся логика мода (чтение из сокетов, анимация Черепашек) должна быть аккуратно встроена в этот цикл.
* **Turtle Entity:** Робот `SHALL` быть реализован как плавно перемещающаяся 3D-сущность (Entity/ObjectRef), а не как статичный блок (Node), чтобы не застревать в собственных постройках и не ломать физику движка.
* **Time Slicing (Нарезка времени):** Архитектурный паттерн. Если сервер получает команду `bulk_set_nodes` на 10 000 блоков, он ставит только 500 блоков в текущем `globalstep`, а остальные откладывает на следующие такты.
* **Barrier (Невидимый барьер):** Специальный кастомный блок (`voxel_bot:barrier`), генерируемый вокруг участков. Защищает участки от протекания воды/лавы и гриферства.
* **Mod Storage:** Встроенное в Luanti SQLite-хранилище (Key-Value), используемое для персистентного сохранения PIN-кодов участков и записанных "пленок" (Tape) между рестартами сервера.
