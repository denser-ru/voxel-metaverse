# PROJECT: Web Gateway & Infra (The Showcase Node)

> **ABSTRACT:** Данный файл описывает бизнес-смысл, целевую аудиторию и высокоуровневую архитектуру веб-шлюза и инфраструктуры развертывания (Docker/Nginx). ИИ-агенты `SHALL` использовать этот документ для понимания своей роли в обеспечении бесшовного доступа (Zero-Install) к воксельным мирам.

## 1. System Passport (Бизнес-миссия: "Что и Зачем")

**Продукт:** Контейнеризированный обратный прокси-сервер, мост протоколов и фронтенд-оболочка для WebAssembly-клиента Luanti.
**Целевая аудитория (Конечный пользователь):** Гости (родители, друзья, одноклассники), которые получают URL-ссылку на конкретный Участок. Они используют обычные браузеры (Chrome, Safari, Edge) на мобильных и десктопных устройствах.

**Глобальная цель (The Why):** 
Полное устранение "трения" (Friction) при входе. Гость `SHALL NOT` устанавливать лаунчеры, разбираться в IP-адресах, портах или создавать аккаунты. Взаимодействие должно сводиться к одному клику по ссылке вида `https://play.domain.com/?plot=12`. Шлюз обязан мгновенно доставить Wasm-движок в браузер, пробросить сетевые порты и автоматически авторизовать гостя в режиме наблюдения (Spectator).

## 2. Architectural Boundaries (Границы Архитектуры)

Рабочее пространство `web-gateway` является мостом между `[[Guest Browser]]` и `[[Server Node]]`.

* **Изоляция от игровой логики:** Шлюз ничего не знает о том, как Черепашка строит блоки или как работает Python SDK. Его задача — исключительно сеть и статика.
* **Protocol Bridging (Трансляция протоколов):** Браузеры физически не могут отправлять UDP-пакеты (стандартный протокол Luanti). Шлюз `SHALL` выступать транслятором, прозрачно упаковывая TCP/WebSocket-трафик от браузера в UDP-датаграммы для локального сервера.
* **Immutable Infrastructure (Неизменяемость):** Все Docker-контейнеры шлюза `SHALL` быть stateless (без сохранения состояния). Любые изменения в файловой системе контейнера после запуска `SHALL NOT` влиять на работу системы. Файлы конфигурации и статика монтируются в режиме Read-Only.
* **Aggressive Caching (Скорость доставки):** Поскольку бинарные файлы движка весят мегабайты, шлюз `SHALL` обеспечивать максимальное кэширование на стороне клиента и сжатие трафика "на лету", чтобы повторные открытия ссылки происходили мгновенно.

## 3. Infra Domain Glossary (Глоссарий Инфраструктуры)

* **Wasm (WebAssembly):** Скомпилированная под браузер версия десктопного клиента Luanti. Состоит из `.js` загрузчика, бинарника `.wasm` и виртуальной файловой системы `.data`.
* **Websockify (Прокси-мост):** Сервисный демон, который слушает WebSocket (TCP) и перенаправляет сырые байты в UDP-порт игрового сервера.
* **Bootstrapper (JS Загрузчик):** Фронтенд-скрипт на странице `index.html`. Извлекает параметры `plot_id` из URL, генерирует временный никнейм и передает их как аргументы командной строки в Wasm-движок (пропуская Главное Меню игры).
* **VFS (Virtual File System):** Файл ресурсов (`.data`), который Emscripten монтирует в память браузера для эмуляции локального диска игры. Требует правильных MIME-типов от Nginx для корректной загрузки.
